# RURCoin Telegram Mini App

Российская криптовалюта с майнингом и стейкингом.

## 🚀 Запуск

### Вариант 1: GitHub Pages (онлайн)
Открой: https://lucifer64-ai.github.io/rurcoin-mini-app/

### Вариант 2: Локально

```bash
# Клонировать репозиторий
git clone https://github.com/Lucifer64-ai/rurcoin-mini-app.git
cd rurcoin-mini-app

# Запустить сервер
npx serve .
# или
python -m http.server 8000
```

Открой http://localhost:8000

### Вариант 3: Telegram Mini App

1. Задеплой на Vercel/Netlify/Cloudflare Pages
2. Создай бота через @BotFather
3. Отправь /newapp -> выбери бота -> укажи ссылку на хостинг

## 📁 Файлы

- `index.html` — главная страница
- `style.css` — стили
- `script.js` — логика майнинга
- `contracts.js` — смарт-контракты
- `sw.js` — Service Worker
- `manifest.json` — PWA манифест

## 🔧 Технологии

- HTML5, CSS3, JavaScript
- PWA (Progressive Web App)
- Telegram Mini App API
